Коды сегментов памяти (SPEICHERSEGMENT)

Аргумент джобов SPEICHER_LESEN/SPEICHER_SCHREIBEN — нужны для низкоуровневого доступа к flash в обход coding-слоя.

SEG_BYTEИмяСмысл
0x00LARlinearAdressRange
0x01ROMIROM/EPROM, внутренний
0x02ROMXROM/EPROM, внешний
0x03NVRAMNV-RAM (характеристики, память DTC)
0x04RAMISRAM внутренний (short MOV)
0x05RAMXXRAM внешний (x data MOV)
0x06FLASHFlash EPROM, внутренний — то, что нужно для доступа к 0xFFC000–0xFFFFFF
0x07UIFMUser Info Field Memory
0x08VODMVehicle Order Data Memory
0x09FLASHXFlash EPROM, внешний
0x0BRAMILRAM внутренний (long MOV / регистры)
0xFF???неизвестный сегмент

SPEICHER_LESEN(SEGMENT, ADRESSE, ANZAHL) принимает имя сегмента строкой, ANZAHL — 1…254 за один вызов. Для 0xFFC000–0xFFFFFF: SEGMENT="FLASH", ADRESSE=0xFFC000, цикл по 254 байта.

Известные адреса и патчи (DKOML2)

Из tools/patcher/kombi_patcher.py — конкретные, опробованные на дампах смещения внутри образа flash.

АдресМодуль патчераЧто это
0xF83DEE8HP shiftlightглиф пробела (0x20) → глиф цифры «8» (0x38), рендер 8-й передачи на экране
0xFB99588HP shiftlightлимит максимальной отображаемой передачи D7 → D8
0xFB9FF0ACC shiftlight«карман» в прошивке (8 208 Б свободного места) — инжекция собственного F2MC-кода полосок ACC-шкалы
0xFBA060Телеметриявторой «карман» (Pocket H2) — диспетчер страниц мультиплексора (ОЖ, масло, бак, скорость)
0xFDC1CDТелеметрияхук в диспетчер нажатия кнопки BC → переключение страниц телеметрии
0xFC2FCANeedle sweepподмена вызова на штатную процедуру самотеста приборки при старте (развёртка стрелок)
0xFFC000–0xFFFFFF—защищённая область (загрузчик + векторы CPU); не пишется ни одним штатным .0pa/.0ba, требует дампа через SPEICHER_LESEN или UART Boot ROM
