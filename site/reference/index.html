SPEICHER_LESEN(SEGMENT, ADRESSE, ANZAHL): сегмент передаётся строкой, ANZAHL — 1…254 за вызов. Для 0xFFC000–0xFFFFFF: SEGMENT="FLASH", ADRESSE=0xFFC000, цикл по 254 байта.

SPEICHER_LESEN(SEGMENT, ADRESSE, ANZAHL): the segment is passed as a string, ANZAHL is 1…254 per call. For 0xFFC000–0xFFFFFF: SEGMENT="FLASH", ADRESSE=0xFFC000, loop in 254-byte steps.

Адреса из черновика патчера (DKOML2)Addresses from the patcher draft (DKOML2)

Модули черновика удалены, не прошивать. Ранний черновик tools/patcher/kombi_patcher.py содержал четыре модуля. Аудит 2026-10-24 (дизассемблер + спецификация набора команд F2MC-16LX + реальные образы) показал, что машинный код шифтлайта и телеметрии невалиден (например, байт 0x12 подписан как CALLP, а на деле это SUBDC A; CALLP — это 0x65), needle sweep ничего не меняет, а смысл патча 8 передач подтверждён не до конца. Все четыре удалены. Теперь в патчере только проверенный патч температуры ОЖ на экране бортового компьютера, и он ложится только на 9213308A: перед записью патчер сверяет исходные байты и на другом образе ничего не пишет. Подробности — HANDOFF.md, раздел «аудит kombi_patcher.py». Draft modules removed — do not flash them. The early draft, tools/patcher/kombi_patcher.py, had four modules. An audit on 2026-10-24 (disassembler + F2MC-16LX instruction set spec + real images) showed that the machine code in the shift-light and telemetry modules is invalid (e.g. byte 0x12 is labelled CALLP but is actually SUBDC A; CALLP is 0x65), the needle sweep changes nothing, and the meaning of the 8-gear patch is only partly confirmed. All four are gone. The patcher now holds only the verified coolant temperature patch for the trip computer display, and it applies to 9213308A only: the patcher checks the original bytes first and writes nothing to any other image. Details: HANDOFF.md, section “аудит kombi_patcher.py”.
