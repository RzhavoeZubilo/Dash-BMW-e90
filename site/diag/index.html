Диагностика приборки из браузераCluster diagnostics in the browser BETA

Первый шаг к «комбайну»: подключение к машине прямо со страницы, без EDIABAS, Java и установки программ. Сейчас страница умеет одно — прочитать идентификацию приборки (джоб IDENT). Она только читает и ничего не записывает в блок.

The first step towards an all-in-one tool: talk to the car straight from a web page — no EDIABAS, no Java, nothing to install. For now the page does one thing: read the cluster identification (the IDENT job). It only reads and never writes anything to the module.

Что нужно: Chrome или Edge на компьютере (Safari и Firefox не умеют работать с COM-портом), кабель K+DCAN, машина с D-CAN (E9x примерно с 03/2007) и включённое зажигание. Машины старше — на K-линии, эта версия их не поддерживает. You need: desktop Chrome or Edge (Safari and Firefox cannot access serial ports), a K+DCAN cable, a D-CAN car (E9x from roughly 03/2007) and the ignition on. Older cars use the K-line, which this version does not support.
Этот браузер не поддерживает Web Serial. Откройте страницу в Chrome или Edge на компьютере. This browser does not support Web Serial. Open the page in desktop Chrome or Edge.

Как это устроеноHow it works

Кабель K+DCAN сам переводит запросы в кадры CAN, поэтому браузеру достаточно открыть COM-порт на 115200 бод и отправить телеграмму BMW-FAST: 82 60 F1 1A 80 6D — «адресату 0x60 (приборка) от тестера F1: сервис $1A ReadEcuIdentification, идентификатор 80», последний байт — контрольная сумма. Байты запроса и разбор ответа взяты из байткода джоба IDENT в заводском KOMB87.prg; подробности — D-CAN_TRANSPORT_RESEARCH.md.

The K+DCAN cable turns requests into CAN frames itself, so the browser only has to open the serial port at 115200 baud and send a BMW-FAST telegram: 82 60 F1 1A 80 6D — “to module 0x60 (cluster) from tester F1: service $1A ReadEcuIdentification, identifier 80”, with a checksum as the last byte. The request bytes and the response layout come from the bytecode of the IDENT job in the factory KOMB87.prg; details in D-CAN_TRANSPORT_RESEARCH.md (Russian).

Если не отвечаетNo answer?

  • Зажигание должно быть включено (клемма 15).
  • Снимите или поставьте галочку DTR/RTS и попробуйте снова — разные кабели ведут себя по-разному.
  • На Windows в свойствах COM-порта FTDI выставьте Latency Timer = 1 мс.
  • Пришлите содержимое окна «Обмен с кабелем» в обсуждение на GitHub — по нему видно, где застряло.
  • The ignition must be on (terminal 15).
  • Toggle the DTR/RTS checkbox and retry — cables differ.
  • On Windows set the FTDI COM port Latency Timer to 1 ms.
  • Post the “Cable traffic” log in a GitHub discussion — it shows where things stopped.
