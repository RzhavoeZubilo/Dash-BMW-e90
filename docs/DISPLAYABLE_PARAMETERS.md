# Что можно вывести на экран приборки

Приборка показывает только то, что **меряет сама** или что **приходит ей по
шине**. Всё остальное (температура масла АКПП, наддув) потребует внешнего
источника, и кастомная прошивка тут не поможет.

Источники этого списка:

- **DBC-mega-merge** (`bmw_e9x_e8x1_merged.dbc`) — сообщения и сигналы,
  у которых получатель указан как `Kombi`. Пометки получателей в DBC
  составлены сообществом и неполны: например, `0x0AA` (обороты) там не
  адресован приборке, хотя тахометр их показывает. Поэтому отсутствие
  `Kombi` в списке получателей — не доказательство, что сообщение до неё
  не доходит.
- **Находки в прошивке** — `docs/research/ANALYSIS_NOTES.md` (адреса RAM).
- **Скрытое меню приборки** — `can-display/docs/cluster-menu.md`.
- **Разведка шин** — `can-display/README.md` (что лежит на PT-CAN, что на K-CAN).

Окончательный ответ на «что доходит до приборки» дал бы лог K-CAN с живой
машины: снифер есть в `can-display` (`pio run -e sniffer`).

## 1. Найдено в прошивке — можно выводить уже сейчас

| Параметр | Где лежит | Формула | Откуда берётся |
|---|---|---|---|
| Температура ОЖ | RAM `0x413A` | `raw − 48 = °C`, `0xFF` — нет данных | CAN `0x1D0` байт 0 от DME |
| Напряжение бортсети | RAM `0x0FA0` | уже в мВ | собственный АЦП приборки, канал 1 |
| Передача / режим АКПП | RAM `0x09FB`, буфер `0x4140` | см. журнал | CAN `0x1D2` от EGS |

Для ОЖ готов и проверен в эмуляторе патч-обработчик (39 байт, см.
`docs/research/HANDOFF.md`, раздел про температуру ОЖ на экране BC).

## 2. Приборка меряет или считает сама — адрес ещё надо найти

Эти величины точно есть внутри прошивки: приборка либо меряет их сама, либо
показывает штатно, либо сама рассылает другим блокам.

| Параметр | Почему точно есть |
|---|---|
| Наружная температура | свой датчик NTC на АЦП, канал 5 (найдена таблица кривой `0xF8199A`); приборка рассылает `0x2CA` |
| Часы и дата | приборка — источник времени в машине, рассылает `0x2F8` |
| Топливо: литры, левый/правый бак | датчики-поплавки подключены к приборке; джоб `STATUS_TANKINHALT`, пункт меню `06.00`; сырьё также в `0x349` |
| Запас хода | рассылает `0x366`/`0x330` |
| Средний расход, средняя скорость | рассылает `0x362` |
| Пробег, суточный | показывает штатно |
| Скорость, обороты | показывает стрелками; источники `0x1A0`/`0x0CE`/`0x1A6` и `0x0AA` |
| Мгновенный расход | штатный бортовой компьютер; `0x1D0` содержит `IJV_FU` (объём впрыска) |

## 3. Приходит на приборку по шине — распаковщик не найден

Сообщения адресованы `Kombi` в DBC. Значения, скорее всего, уже лежат в
RAM, но где — пока не установлено.

| Параметр | Сообщение | Сигнал, формула | Замечания |
|---|---|---|---|
| Температура масла двигателя | `0x1D0` | `TEMP_EOI`, байт 1, `raw − 48` | только бензин; на N47 всегда `0xFF` |
| Атмосферное давление | `0x1D0` | `AIP_ENG`, байт 3, `raw × 2 + 598` гПа | можно показывать как высоту над уровнем моря |
| Целевые обороты ХХ | `0x1D0` | `RPM_IDLG_TAR`, `raw × 5` об/мин | |
| Продольное ускорение | `0x1A0` | `LongAcc`, 12 бит × 0.025 м/с² | g-метр |
| Поперечное ускорение | `0x1A0` | `LatlAcc`, 12 бит × 0.025 м/с² | g-метр |
| Скорость рысканья | `0x1A0` | `YawRate`, 12 бит × 0.05 °/с | |
| Скорости колёс | `0x0CE` | 4 × 16 бит × 0.0625 км/ч | например, проскальзывание |
| Давление в тормозах | `0x19E` | `BrakePressure`, байт 6 | масштаб не описан |
| Дистанции парктроника | `0x1C2` | 8 датчиков, см | |
| Уставка круиз-контроля | `0x193` / `0x200` | км/ч | |
| Уровень масла | `0x381` | коды состояния | |
| Координаты GPS | `0x34A` | широта/долгота | только с навигацией CCC/CIC |

## 4. До приборки не доходит

| Параметр | Почему |
|---|---|
| Температура масла АКПП | `0x0B5` `TEMP_GRB` есть только на PT-CAN (`can-display/README.md`); в K-CAN шлюз его не пропускает |
| Давление наддува | в DBC не найдено ни в одном сообщении |
| Температура впуска | в DBC не найдено |
| Положение педали газа, крутящий момент | `0x0AA`/`0x0A8` адресованы EGS/DSC; доходят ли до приборки — проверить логом K-CAN |

## Открытые вопросы, связанные с отображением

- **Где хранятся значки и шрифт.** Значки ОЖ, масла, аккумулятора, топлива
  одинаковые у стоковых сообщений Check-Control и у кастомных прошивок —
  скорее всего, они лежат в ПЗУ, а моды вызывают штатную отрисовку.
  Быстрый поиск битмапов в формате «1 бит на точку, строками» по образу
  DKOML2 ничего не дал (найденные повторы `0x66` — это код `RETP`). Экран
  4 бита на точку — возможно, хранение 4bpp, по столбцам или со сжатием.
- **Разрешение экрана.** Джоб `STEUERN_TESTBITMAP` выводит на экран
  тестовое изображение. Его обработчик в прошивке должен рисовать на
  всю площадь — хороший кандидат, чтобы найти ширину и высоту в точках.
