# komb87.prg — русские пояснения к джобам

Источник истины для **значения** каждого джоба — `KOMB87_JOBS.md` (оригинальный
немецкий комментарий BMW из самого SGBD, нем. "Kommentar"). Этот файл — отдельный,
человеческий перевод/пояснение на русском для сайта (колонка "Комментарий" в
справочнике), чтобы не редактировать построчный формат основного файла и не
путать немецкий официальный текст с нашей трактовкой.

Формат: `- \`ИМЯ_ДЖОБА\` -- русский текст`, один джоб на строку, порядок
значения не имеет (сшивается по имени в `tools/site/build_jobs_data.py`).
Если для джоба здесь нет строки — на сайте колонка "Комментарий" будет пустой
(лучше пусто, чем выдуманное пояснение).

- `INFO` -- служебная информация о самом SGBD (версия, описание) — не про щиток, а про файл диагностики
- `INITIALISIERUNG` -- открывает диагностическую сессию и задаёт параметры связи (скорость, протокол) перед остальными джобами
- `DIAGNOSEPROTOKOLL_LESEN` -- узнать, какие диагностические протоколы (KWP2000 и т.п.) поддерживает щиток
- `DIAGNOSEPROTOKOLL_SETZEN` -- выбрать диагностический протокол для текущей сессии
- `IDENT` -- прочитать идентификационные данные щитка (номер детали, версия ПО и т.п.) — то же самое, что видно в INPA/ISTA в разделе "идентификация"
- `FS_LESEN` -- прочитать журнал ошибок целиком: все коды неисправностей со статусом (место и тип ошибки)
- `FS_LESEN_DETAIL` -- прочитать подробности одной конкретной ошибки из журнала (все поля по одному коду)
- `FS_LOESCHEN` -- очистить журнал ошибок (аналог кнопки "удалить ошибки" в диагностике)
- `PRUEFSTEMPEL_LESEN` -- прочитать "штамп проверки" — отметку о прохождении заводского/сервисного теста
- `PRUEFSTEMPEL_SCHREIBEN` -- записать "штамп проверки" (используется на заводе/в сервисе после теста)
- `NORMALER_DATENVERKEHR` -- включить или выключить обычный обмен по шине (например, временно "заглушить" щиток на время диагностики)
- `DIAGNOSE_AUFRECHT` -- keep-alive: держать диагностическую сессию открытой (щиток сам выходит из режима диагностики, если его не "пинговать")
- `DIAGNOSE_ENDE` -- штатно завершить диагностическую сессию
- `DIAGNOSE_MODE` -- перевести щиток в определённый диагностический режим (расширенный доступ и т.п.)
- `SLEEP_MODE` -- перевести щиток в спящий режим (энергосбережение)
- `ENERGIESPARMODE` -- настроить режим энергосбережения щитка
- `SPEICHER_LESEN` -- универсальное чтение памяти щитка по сегменту+адресу (ROM/RAM/flash/EEPROM напрямую, в обход коддинга) — именно этот джоб использует `tools/fujitsu_uart_flasher/`-подобный доступ по диагностике
- `SPEICHER_SCHREIBEN` -- универсальная запись в память щитка по сегменту+адресу, низкоуровневый аналог `SPEICHER_LESEN`
- `CBS_INFO` -- версия подсистемы CBS (Condition Based Service — сервисные интервалы "по состоянию")
- `CBS_DATEN_LESEN` -- прочитать данные CBS (остаток до следующих ТО, замены масла и т.д.), версия формата 4
- `CBS_RESET` -- сбросить данные CBS (имитация выполненного сервисного обслуживания)
- `PRUEFCODE_LESEN` -- прочитать стандартный проверочный код для сервисного приёмщика (контроль подлинности/состояния)
- `C_CI_LESEN` -- прочитать индекс кодирования (версию набора параметров FSW/PSW, по которому щиток закодирован)
- `C_FG_LESEN` -- прочитать записанный в щитке VIN (номер кузова)
- `C_FG_SCHREIBEN` -- записать VIN в щиток (привязка к конкретному автомобилю)
- `C_FG_AUFTRAG` -- записать VIN и сразу прочитать обратно для проверки записи
- `C_AEI_LESEN` -- прочитать индекс изменения коддинг-данных (счётчик версий коддинга)
- `C_AEI_SCHREIBEN` -- записать индекс изменения коддинг-данных
- `C_AEI_AUFTRAG` -- записать индекс изменения коддинг-данных и сразу перечитать для проверки
- `C_C_LESEN` -- прочитать блок коддинг-данных (параметры комплектации FSW/PSW)
- `C_C_SCHREIBEN` -- **главный джоб кодирования** — именно его использует NCS Expert/ISTA для записи коддинга (FSW/PSW) через `$22`/`$2E`, диапазон `$3000-$3EFF`
- `C_C_AUFTRAG` -- записать блок коддинг-данных и сразу перечитать для проверки
- `SERIENNUMMER_LESEN` -- прочитать серийный номер производителя (не VIN, а номер самого блока щитка)
- `ZIF_LESEN` -- прочитать "информационное поле поставщика" (служебные данные производителя щитка, Siemens VDO/Johnson Controls)
- `ZIF_BACKUP_LESEN` -- прочитать резервную копию ZIF-поля (на случай повреждения основного)
- `PHYSIKALISCHE_HW_NR_LESEN` -- прочитать физический номер железа (HW-NR) — именно его проверяет WinKFP перед прошивкой, см. раздел про привязку софта к железу в исследовании
- `HARDWARE_REFERENZ_LESEN` -- прочитать референс аппаратной платформы щитка
- `DATEN_REFERENZ_LESEN` -- прочитать референс набора данных (версию прошитых данных/таблиц)
- `FLASH_ZEITEN_LESEN` -- прочитать тайминги прошивки: сколько займёт стирание флеша и проверка подписи (нужно клиенту диагностики, чтобы не обрывать сессию раньше времени)
- `FLASH_BLOCKLAENGE_LESEN` -- прочитать максимальный размер блока данных за одну передачу при прошивке
- `AUTHENTISIERUNG_ZUFALLSZAHL_LESEN` -- первый шаг challenge-response авторизации перед прошивкой: получить от щитка случайное число (challenge)
- `AUTHENTISIERUNG_START` -- второй шаг: отправить ответ (подписанное случайное число) и получить допуск к прошивке
- `FLASH_PROGRAMMIER_STATUS_LESEN` -- узнать текущий статус процесса прошивки (идёт/завершена/ошибка)
- `FLASH_SIGNATUR_PRUEFEN` -- проверить криптографическую подпись прошивки (последний шаг после записи, без успешной проверки новая прошивка не применится)
- `STEUERGERAETE_RESET` -- перезагрузить блок (программный ресет щитка)
- `FLASH_LOESCHEN` -- стереть область флеша перед записью новой прошивки
- `FLASH_SCHREIBEN_ADRESSE` -- подготовка к прошивке: сообщить щитку адрес и размер блока, который сейчас будет передаваться
- `FLASH_SCHREIBEN` -- передать и записать очередной блок данных прошивки во флеш
- `FLASH_SCHREIBEN_ENDE` -- завершить процесс прошивки (финальный шаг после передачи всех блоков)
- `AIF_LESEN` -- прочитать "информационное поле пользователя" (служебная область для заметок/меток, не влияет на работу щитка)
- `AIF_SCHREIBEN` -- записать "информационное поле пользователя"
- `SG_RESET_OHNE_UHR_DATUM` -- перезагрузить блок, не сбрасывая часы и дату (в отличие от обычного ресета)
- `UHRZEIT_DATUM_STELLEN` -- установить время и дату в щитке
- `CODIERDATEN_LESEN` -- прочитать блок коддинга напрямую по номеру блока (диапазон `0x3000-0x3FFF`), более низкоуровневый вариант чтения, чем `C_C_LESEN`
- `C_CHECKSUMME` -- посчитать контрольную сумму блока коддинга перед записью (не крипто-подпись, просто checksum для защиты от битых данных)
- `STEUERN_LEUCHTEN` -- принудительно включить контрольные лампы на щитке (для проверки лампочек сервисменом)
- `STEUERN_LEUCHTEN_BLAU` -- включить только синие контрольные лампы (тест по цвету)
- `STEUERN_LEUCHTEN_GELB` -- включить только жёлтые контрольные лампы (тест по цвету)
- `STEUERN_LEUCHTEN_GRUEN` -- включить только зелёные контрольные лампы (тест по цвету)
- `STEUERN_LEUCHTEN_ORANGE` -- включить только оранжевые/жёлтые контрольные лампы (тест по цвету)
- `STEUERN_LEUCHTEN_ROT` -- включить только красные контрольные лампы (тест по цвету)
- `STEUERN_LEUCHTEN_AUS` -- выключить принудительное управление лампами, запущенное `STEUERN_LEUCHTEN`, вернуть обычный режим
- `STEUERN_BLINKER` -- принудительно включить указатели поворота (сервисный тест)
- `STEUERN_BLINKER_AUS` -- выключить принудительное управление поворотниками, запущенное `STEUERN_BLINKER`
- `STEUERN_SELBSTTEST_EIN` -- включить режим самотестирования щитка (проверка стрелок/экрана/ламп при включении)
- `STEUERN_SELBSTTEST_AUS` -- выключить режим самотестирования
- `STEUERN_TACHO` -- задать произвольное показание спидометра (0..300 км/ч) — временно, только на время сессии, для проверки стрелки/экрана
- `STEUERN_TACHO_AUS` -- выключить принудительное задание скорости, вернуть реальные показания
- `STEUERN_DREHZAHL` -- задать произвольные обороты тахометра (об/мин) — временно, на время сессии
- `STEUERN_DREHZAHL_AUS` -- выключить принудительное задание оборотов, вернуть реальные показания
- `STEUERN_KVA` -- задать произвольный мгновенный расход топлива (л/100км) — временно, на время сессии
- `STEUERN_KVA_AUS` -- выключить принудительное задание расхода, вернуть реальные показания
- `STEUERN_TANK` -- задать произвольный уровень топлива в баке (%) — для проверки стрелки/индикатора
- `STEUERN_TANK_AUS` -- выключить принудительное задание уровня топлива, вернуть реальные показания
- `STEUERN_ACC_ZEIGER` -- задать произвольную скорость для стрелки/индикатора ACC (круиз-контроль) — временно, на время сессии
- `STEUERN_ACC_ZEIGER_AUS` -- выключить принудительное задание для индикатора ACC
- `STEUERN_VWF` -- задать произвольные обороты для стрелки предупредительного поля тахометра (зона перед красной зоной) — временно, на время сессии
- `STEUERN_VWF_AUS` -- выключить принудительное задание оборотов предупредительного поля
- `STATUS_TANKINHALT` -- прочитать "сырые" значения уровня топлива от обоих датчиков-поплавков (1 и 2) в литрах
- `STATUS_A_TEMP_LESEN` -- прочитать температуру воздуха снаружи: и отображаемое значение, и необработанное (сырое) с датчика
- `GWSZ_RESET` -- изменить корректирующее смещение одометра (GWSZ — "скорректированный общий пробег")
- `STATUS_ABSOLUTER_GWSZ` -- прочитать абсолютный (несмещённый) пробег
- `STATUS_GWSZ_OFFSET` -- прочитать текущее смещение пробега (разницу между абсолютным и отображаемым значением)
- `STATUS_GWSZ_ANZEIGE` -- прочитать пробег, который реально показывается на одометре (с учётом смещения)
- `LESEN_AKTUELLES_UIF` -- прочитать текущее "поле информации пользователя" (UIF) щитка
- `LESEN_HW_NUMMER` -- прочитать номер аппаратной версии (HW-Nummer) щитка
- `LESEN_EEPROM_DATENINDEX` -- прочитать индекс (версию) набора данных в EEPROM
- `LESEN_VARIANTENINDEX` -- прочитать индекс варианта (конкретной модификации/комплектации) щитка
- `LESEN_HW_AENDERUNGSINDEX` -- прочитать индекс аппаратных изменений (ревизию платы/железа)
- `LESEN_DIAGNOSEINDEX` -- прочитать индекс версии диагностического ПО щитка
- `LESEN_FERTIGUNGSDATUM` -- прочитать дату изготовления щитка
- `LESEN_LIEFEREANTENNUMMER` -- прочитать номер поставщика (производителя щитка — Siemens VDO/Johnson Controls и т.п.)
- `LESEN_SW_LAYER_VERSION` -- прочитать версии программных "слоёв" (внутренних модулей прошивки)
- `STATUS_TACHO_LESEN` -- прочитать текущую отображаемую скорость (км/ч) — обычное чтение, в отличие от `STEUERN_TACHO`, которое её задаёт
- `STATUS_DREHZAHL_LESEN` -- прочитать текущие обороты двигателя (об/мин)
- `STATUS_LENKSTOCK` -- прочитать состояние подрулевого переключателя (какие кнопки/положения активны)
- `STATUS_KL30_H_OFFSET` -- прочитать смещение счётчика часов работы по клемме 30 (постоянное питание)
- `STATUS_KL30_H_ZAEHLER` -- прочитать сам счётчик часов работы по клемме 30
- `CALC_KL30_H_OFFSET` -- рассчитать смещение счётчика часов клеммы 30 от текущей даты
- `SET_KL30_OFFSET2AKT_DATE` -- применить рассчитанное смещение счётчика часов клеммы 30 к текущей дате
- `STATUS_DATE_LAST_CODING_SESSION` -- прочитать дату, когда щиток последний раз кодировался на заводе/у BMW (только чтение, менять нельзя)
- `STATUS_KLEMMEN` -- прочитать состояние клемм зажигания (30/15/X и т.п. — что сейчас запитано)
- `C_FG_LESEN2` -- альтернативный/резервный джоб чтения VIN (дублирует `C_FG_LESEN`)
- `STATUS_KLEMMENSPANNUNG` -- прочитать напряжение питания щитка (бортовая сеть)
- `STATUS_CHECKCONTROL_LESEN` -- прочитать ID-номера сообщений Check Control, активных прямо сейчас
- `STATUS_BETRIEBSDATEN_HEADER` -- прочитать пробег из заголовка эксплуатационных данных CBS
- `STATUS_BETRIEBSDATEN_LESEN` -- прочитать выбранные эксплуатационные данные CBS (детали по интервалам обслуживания)
- `STATUS_ZEITSTRAHL` -- выдать данные CBS "по временной шкале" для сервисного калькулятора приёмки (когда что нужно обслужить)
- `STEUERN_CBS_KM_PER_YEAR` -- задать среднегодовой пробег для расчётов CBS (сервисных интервалов)
- `STEUERN_CBS_SC_CODIERUNG` -- включить/выключить кодирование service-call для CBS (похоже на коддинг, но отдельный механизм)
- `STATUS_CBS_WOCHEN_KM` -- прочитать данные алгоритма "км в неделю" из заголовка эксплуатационных данных CBS
- `MOTORTYP` -- определить тип двигателя, закодированный в щитке (из коддинг-данных)
- `STEUERN_TESTBITMAP` -- вывести тестовое изображение (битмап) на экран щитка — удобно для проверки всех пикселей/сегментов сразу
- `STEUERN_TESTBITMAP_AUS` -- убрать тестовое изображение, вернуть обычный экран
- `STATUS_CHECKCONTROL_HISTORY` -- прочитать историю (архив) сообщений Check Control из памяти щитка
- `ZEIGERZAHL` -- определить по коддинг-данным количество реальных стрелок в щитке (разные комплектации — разное число приборов)
- `STATUS_BOS_CODIERUNG` -- прочитать коддинг CBS по каждому отдельному показателю обслуживания (масло, тормоза и т.д.)
- `STEUERN_BOS_CODIERUNG` -- записать коддинг CBS по каждому отдельному показателю обслуживания
- `STATUS_GLOBAL_KM` -- прочитать пробег сразу из трёх источников — RAM щитка, EEPROM и блока CAS — для сверки
- `STATUS_KI` -- прочитать произвольный блок данных щитка (служебный, параметр "какой блок" передаётся отдельно)
- `RINGBUF_INIT` -- инициализировать кольцевой буфер (сбросить служебную очередь записей перед её использованием)
- `LESEN_RINGBUF` -- прочитать содержимое кольцевого буфера
- `STATUS_NTC1` -- прочитать "сырое" значение АЦП с канала 3 (термистор NTC1 — один из температурных датчиков щитка)
- `LESEN_CODIERBLOCK` -- низкоуровневое чтение блока коддинга прямо из EEPROM (ещё более низкий уровень, чем `CODIERDATEN_LESEN`)
- `RESTORE_PIA_DEFAULT` -- сбросить ключи PIA (защищённый доступ/аутентификация) на заводские значения по умолчанию
- `LESEN_PIA_WERTE` -- прочитать текущие значения ключей PIA
- `STEUERN_CCG` -- принудительно включить звуковой сигнал Check Control (гонг) — сервисная проверка звука
- `STEUERGERAETE_RESET_DELAY` -- перезагрузить блок с задержкой (не мгновенно, как обычный `STEUERGERAETE_RESET`)
- `STEUERN_ATEMP_RESET` -- сбросить алгоритм расчёта температуры воздуха (перенести "сырое" значение сразу в отображаемое, без сглаживания)
- `LESEN_HW_AENDERUNGSINDEX_PRODUKTIONSORT` -- прочитать индекс аппаратных изменений с учётом места производства (альтернативный вариант `LESEN_HW_AENDERUNGSINDEX`)
- `STATUS_CBS_ANZEIGE` -- прочитать, что именно сейчас показывается на экране по сервисным интервалам CBS
- `STEUERN_ANPASSEN_ACC_KENNLINIE_SVDO` -- откалибровать характеристику (кривую) стрелки/индикатора ACC — пишет в NVRAM напрямую, без крипто-подписи
- `STEUERN_ANPASSEN_LCD_KENNLINIE_SVDO` -- откалибровать характеристику (кривую) LCD-индикатора — пишет в NVRAM напрямую, без крипто-подписи
