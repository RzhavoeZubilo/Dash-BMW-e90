# Инструкция к прошивальщику Fujitsu MB90F395HA (fujitsu_flasher.py)

Скрипт [`fujitsu_flasher.py`](fujitsu_flasher.py) предназначен для снятия полного дампа Flash-памяти и последующей прошивки микроконтроллеров Fujitsu F2MC-16LX (MB90F395HA / MB90F394H), используемых в щитках приборов BMW E90 (DKOML2).

---

## 1. Подготовка окружения

Для работы скрипта требуется библиотека `pyserial`:
```bash
pip3 install pyserial
```

---

## 2. Подключение аппаратуры

1. Переведите переходник USB-UART в режим **5V** (джампер питания).
2. Подключите провода согласно схеме [FUJITSU_MB90F395_UART_PINOUT.md](../docs/hardware/FUJITSU_MB90F395_UART_PINOUT.md):
   * **TXD** переходника $\rightarrow$ **Pin 7 (SIN0 / RX)** процессора
   * **RXD** переходника $\rightarrow$ **Pin 5 (SOT0 / TX)** процессора
   * **GND** переходника $\rightarrow$ **Pin 16 (GND)** процессора
   * **Pin 87 (MD2)** процессора $\rightarrow$ **GND** (активация Bootloader)
3. Подайте +12 В на разъем приборки X11175 (Pin 9 = +12V, Pin 18 = GND).
4. Кратковременно замкните **Pin 90 (RST)** на GND (для перезагрузки в режим загрузчика).

---

## 3. Команды использования

### Снятие полного дампа Flash (512 КБ):
```bash
python3 fujitsu_flasher.py -p /dev/tty.usbserial-XXXX -o kombi_stock_backup.bin
```
*(Для Windows: замените порт на соответствующий COM-порт, например `-p COM3`)*.

### Параметры запуска:
* `-p, --port`: порт адаптера (обязательный параметр)
* `-o, --output`: имя файла для сохранения дампа (по умолчанию `kombi_fujitsu_backup.bin`)
* `-b, --baud`: скорость авто-синхронизации (по умолчанию `9600`)
* `--size`: размер памяти в килобайтах (по умолчанию `512` КБ для MB90F395HA)
* `--start`: базовый 24-битный адрес Flash (по умолчанию `0xF80000`)
