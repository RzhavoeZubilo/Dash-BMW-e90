# Эмулятор стенда приборной панели BMW E90 (Bench Emulator)

Скетч для Arduino (Nano / Uno) с модулем **MCP2515** для запуска и управления приборной панелью BMW E90 (DKOML2 / HKOML2) на рабочем столе.

---

## 1. Схема подключения

### Питание
* **Arduino:** питается от компьютера по **USB** (+5 В).
* **Приборная панель:** питается от отдельного блока питания **12 В** (1.5–2 А).

> [!IMPORTANT]
> **Плюсы питания (+5 В USB и +12 В) НЕ соединяются!**
> **Минусы (GND) ОБЯЗАТЕЛЬНО соединяются вместе** одним проводком: пин `GND` платы Arduino соединяется с минусом блока питания 12 В (или пином 18 разъема приборки). Это создает единый опорный ноль для CAN-трансивера.

### Разъем приборной панели (18-контактный черный разъем X11175)
| Пин приборки | Назначение | Куда подключать |
|---|---|---|
| **Пин 9** | `+12V Kl.30` | `+12V` блока питания |
| **Пин 18** | `GND Kl.31` | `GND (минус)` блока питания и `GND` Arduino |
| **Пин 6** | `K-CAN High` | Клемма `CANH` модуля MCP2515 |
| **Пин 7** | `K-CAN Low` | Клемма `CANL` модуля MCP2515 |

### Соединение Arduino Nano ──► MCP2515
| Arduino Nano | Модуль MCP2515 |
|---|---|
| `5V` | `VCC` |
| `GND` | `GND` |
| `D10` | `CS` |
| `D11` | `MOSI (SI)` |
| `D12` | `MISO (SO)` |
| `D13` | `SCK` |

* **Джампер J1 на плате MCP2515:** должен быть **замкнут** (терминатор 120 Ом активен).

---

## 2. Управление через Serial Monitor

Откройте монитор порта в Arduino IDE на скорости **115200 бод**:
* `w` / `s` — плавно поднять / опустить стрелку тахометра (`+/- 500 RPM`)
* `p`, `r`, `n`, `d`, `m` — переключить селектор АКПП (`[P]`, `[R]`, `[N]`, `[D]`, `[M]`)
* `1` .. `8` — выбор номера передачи в ручном режиме (`M1` .. `M8`)
* `a` — переключение ступеней полосок ACC (0 $\to$ 1 $\to$ 2 $\to$ 3 $\to$ 4 $\to$ стробоскоп)
* `t` — включить демонстрационный авто-sweep (стрелка плавно бегает 0–7000 об/мин с автоматическим включением шифтлайта на полосках ACC)
