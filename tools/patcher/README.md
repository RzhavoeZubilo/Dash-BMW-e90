# BMW Kombi (DKOML2) Firmware Patcher (`kombi_patcher.py`)

Инструмент автоматической сборки кастомных прошивок для щитков приборов BMW E90 (DKOML2, микроконтроллер Fujitsu MB90F395HA).

---

## 1. Назначение

Скрипт [`kombi_patcher.py`](kombi_patcher.py) берет чистый заводской образ SP-Daten (`9283870A.0pa`) или считанный с чипа дамп памяти, накладывает низкоуровневые хуки и патчи в машинных кодах архитектуры Fujitsu F2MC-16LX и генерирует готовый к заливке бинарный образ (512 КБ).

---

## 2. Реализованные модули

1. **8-Speed Gearbox Support (`mod_8speed`):**
   * Разблокировка ступени 8 в цикле обработки селектора (`0xFB9958`: замена опкода `D7` на `D8`).
   * Инжекция глифа `'8'` (`0x38`) в таблицу символов передач по адресу `0xF83DEE`.
   * Позволяет отображать передачи `D1..D8`, `M1..M8`, `S1..S8`.

2. **Progressive ACC Shift-Light (`mod_shiftlight`):**
   * Инжекция ассемблерного кода в неиспользуемый карман Flash-памяти Pocket H2 (`0xFB9FF0`).
   * Пороги переключения в ручном режиме АКПП `[M]`:
     * `< 4000 RPM` $\rightarrow$ полоски выключены.
     * `4000 – 4499 RPM` $\rightarrow$ зажигается 1-я полоска (нижняя).
     * `4500 – 4999 RPM` $\rightarrow$ зажигаются 1-я и 2-я полоски.
     * `5000 – 5199 RPM` $\rightarrow$ зажигаются 1, 2 и 3 полоски.
     * `≥ 5200 RPM` $\rightarrow$ **стробоскоп** (мигание всеми 4 полосками и боковыми рельсами разметки).
     * Силуэт машинки (ID `0x24`) принудительно отключен.

3. **Needle Sweep Upon Ignition (`mod_needle_sweep`):**
   * Перехват обработчика пробуждения по CAN Kl.15 (`0xFC2FCA`).
   * Вызов заводской процедуры полного взмаха и калибровки стрелок `CALL 0xAC65` (KI TEST) при включении зажигания.

---

## 3. Команды запуска

Сборка кастомной прошивки одной командой:
```bash
python3 tools/patcher/kombi_patcher.py -i local-firmware/9283870A.0pa -o kombi_custom_firmware.bin
```

Выходной файл `kombi_custom_firmware.bin` (ровно 524 288 байт / 512 КБ) напрямую готов к заливке в память процессора Fujitsu через наш UART-программатор:
```bash
python3 tools/fujitsu_uart_flasher/fujitsu_flasher.py -p /dev/tty.usbserial-XXXX -i kombi_custom_firmware.bin
```
