# BMW Kombi Firmware Patcher (`kombi_patcher.py`)

Сборка пропатченного образа для щитка приборов BMW E90 (Fujitsu MB90F395HA, F2MC-16LX).

---

## 1. Назначение

Скрипт [`kombi_patcher.py`](kombi_patcher.py) берёт заводской образ SP-Daten (`.0pa`) или
считанный с чипа дамп (`.bin`, 512 КБ с базы `0xF80000`), накладывает **только проверенные
разбором** патчи и пишет бинарный образ на 512 КБ.

Перед записью каждый патч сверяет исходные байты по всем адресам, которые трогает или от
которых зависит. Если хоть один байт не совпал (другой образ, уже пропатченный образ) —
ничего не пишется, выходной файл не создаётся, код возврата 1.

---

## 2. Патчи

1. **Температура ОЖ на BC-дисплее (режим 0)** — только образ `9213308A` (DKOML2).
   * `0xFE996C`: `57 10 16 F1` → `63 F0 9F FB` (`JMPP 0xFB9FF0`) — начало дефолт-обработчика
     режима 0 диспетчера `0xFE979E`.
   * `0xFB9FF0`: 35 байт обработчика в стёртой области (`0xFF`): `[0x413A] − 48` → °C × 10,
     «нет данных» → `0xFFFE`, выход `JMPP 0xFE99A5`.
   * Байты и обоснование — [`docs/research/HANDOFF.md`](../../docs/research/HANDOFF.md),
     раздел «Итоговые байты обработчика»; проверка исполнением — `tools/re/f2mc_mini_emu.py`;
     тест — `tests/patcher/test_kombi_patcher.py`.
   * На железе ещё не проверялся.

Модули раннего черновика (8 передач, shift-light на ACC, телеметрия, needle sweep) удалены
2026-10-24: в shift-light и телеметрии байты не являются валидным кодом F2MC-16LX, needle
sweep на `9283870A` ничего не меняет, а на других образах бьёт посреди инструкции, у 8 передач
механика подтверждена только на `9283870A`, а смысл значения — нет. Разбор — HANDOFF.md,
раздел «2026-10-24: аудит kombi_patcher.py».

---

## 3. Команды запуска

```bash
python3 tools/patcher/kombi_patcher.py -i local-firmware/9213308A.0pa -o kombi_custom_firmware.bin
```

Выходной файл — ровно 524 288 байт (512 КБ), образ для UART-программатора
(`tools/fujitsu_uart_flasher/`).
